# Demo Script

1. Login sebagai admin@kantin.test.
2. Buka /admin/tables, tambahkan meja.
3. Klik "Terbitkan QR"; salin URL /q/... (hanya tampil sekali).
4. Buka URL itu di tab baru -> diarahkan ke /kantin/kantin-pusat.
5. Muat ulang halaman QR admin -> URL tidak tampil lagi.
6. Terbitkan ulang QR -> URL lama tidak berlaku.
